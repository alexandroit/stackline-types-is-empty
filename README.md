## Why this package?

`@stackline/types-is-empty` is the Stackline-maintained distribution of `@types/is-empty@1.2.3`. It is an independent continuation of [@types/is-empty](https://github.com/DefinitelyTyped/DefinitelyTyped); original authors and licenses remain credited below.

## Installation

```bash
npm install --save-dev @stackline/types-is-empty
```

Preserve existing imports and plugin resolution with an npm alias:

```bash
npm install --save-dev @types/is-empty@npm:@stackline/types-is-empty
```

Use the original `@types/*` alias for automatic TypeScript type discovery and existing `compilerOptions.types` settings. A scoped-only installation does not automatically expose the original type-package name.
